# СамоедАвто — samoед-taxi

Сайт такси ООО «СамоедАвто» (Пинск). Главное действие — заявка на поездку.

Стек: React + Vite + TypeScript, GSAP + ScrollTrigger, Lenis. Статика, один экран-приложение.
Деплой: GitHub Pages через Actions.

## Что внутри
- `src/components/Talon.tsx` — пин-сцена «талон»: бумажная заявка выезжает из щели по скроллу (только десктоп, при reduced-motion статично).
- `src/components/Order.tsx` — форма заявки с валидацией (адрес, телефон, время) и живой черновик справа; отправка собирает текст и открывает WhatsApp.
- `src/components/Trips.tsx` — частые поездки и что указать.
- `src/components/Faq.tsx` — вопросы, включая отсутствие цен на сайте.
- `docs/design-brief.md` — художественное задание и ход работы.

## Локально
```
npm install
npm run dev
```
Иконки и постеры тарифов: графические токены в CSS, изображений нет.
